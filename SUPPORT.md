# Support

Liftr is an early-stage open-source project maintained on a best-effort basis.
There is currently no commercial support or response-time guarantee.

## Getting Help

Before opening an issue:

1. Read the [README](README.md), [architecture documentation](docs/architecture.md),
   and [runbook](docs/runbook.md).
2. Search existing GitHub issues and discussions.
3. Reduce the problem to a minimal, reproducible example.

Use a GitHub issue for reproducible defects and focused feature requests.
Include relevant versions, configuration with secrets removed, the expected
behavior, and the actual behavior.

## Security Issues

Do not report vulnerabilities in a public issue. Follow
[SECURITY.md](SECURITY.md) instead.

## Project Scope

Support covers Liftr itself. Deployment-specific cloud, Kubernetes,
provisioner, identity-provider, and Backstage administration may require help
from the corresponding upstream project or service provider.
